# Bazar Dor

## Description
Bazar Dor is a web-based platform that displays market prices of various products, including vegetables. Users can compare product prices and analyze average market rates to better understand price variations.

## Technologies Used
- Next.js
- React
- Tailwind CSS
- daisyUI
- HeroUI
- Better Auth
- MongoDB

## Features
- Displays products with increasing and decreasing prices.
- Lists products by category.
- User authentication.
- Product marquee displaying market products.
- Product sorting on category pages.
